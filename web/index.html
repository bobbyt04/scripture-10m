Code, data pipeline, training and evals: github.com/bobbyt04/scripture-10m. No pretrained weights, no external services, no tracking.

Translations: Bhagavad Gita, Annie Besant (4th ed., 1922, via Wikisource); Quran, Marmaduke Pickthall (1930, via Project Gutenberg, public domain in the US since 2026); Bible, King James Version (eBible.org; public domain outside the UK, where the Crown holds printing rights).
