    Translations

    • Bhagavad Gita: Annie Besant, 4th edition, 1922, via Wikisource. Public domain.
    • Quran: Marmaduke Pickthall, 1930, via Project Gutenberg. Public domain in the US since 2026.
    • Bible: King James Version, eBible.org text. Public domain (outside the UK, where the Crown holds printing rights).
